#

The following is a set of performance tests to run on Sparse program.
It takes five example input files and compares results to correct
model outputs. It also includes a testing client for List and Matrix
ADT's.

## Usage

The tests will print out the difference between output and the correct output,
using the `diff` command.

The ListTest and MatrixTest will list all of unit tests they perform and which
passed/failed.
